# Frozen research baseline A-80cb25df5552621e

These JavaScript files are the compiled numerical research modules from commit
`6ed36d449418fc155f39f37371bc8c1ef5b56846` (the deployed C906 baseline).
The matching TypeScript sources in that commit are unchanged in the historical
web compatibility worktree. The declaration files are generated from those
sources and exist for the current TypeScript consumers. They are part of this
project, under its existing licensing terms.

The original ForecastCore fingerprints every compiled file in `models` and
`config`, plus the four named dependencies; consequently those directories are
complete even where an individual module is not called for a particular match.
The remaining JS files are the transitive numerical dependencies and both
research probability pipelines. They do not initialize an application, database,
or external provider. The public research modules re-export this snapshot;
operational A continues to use the current application models.

`integrity.json` records the SHA-256 of every frozen JS file. Prebuild rejects
missing, changed or extra JS before copying the snapshot into `dist`, preserving
identical bytes in builds and TypeScript development mode. Do not edit these
files in place: a new mathematical baseline needs a new version and separately
validated artifacts. The historical baseline fingerprint is computed by the
original code from the real snapshot bytes, not replaced with a constant.
The corresponding coherent pipeline hash is
`0f347c99dae92413322c937856d3ac6fb2c36e08e0c86e83b7c0b753cb222c81`.

`test/fixtures/frozen-baseline-6ed36d44.json` was generated by executing the
historical compiled release on the deterministic inputs in
