# Current challenger

`challenger.json` is the sole packaged C artifact. Its identity is pinned in
`CurrentChallengerRelease.ts`. The opportunity_guard recipe packages the exact
existing 2026 six-class classifier, coherent probability configuration,
prequential reliability and opportunity-guard profiles; packaging does not fit
new models. The approved scope is 1X2, total goals 2.5 and Asian handicaps with
`c-resolved-engine-ranking-v1` and `c-opportunity-guard-markets-v1`.
Operational adoption is a user decision, not a claim of independent statistical
validation (`productionValidated` and `independentEvidence` remain false).
Its model, baseline,
configuration and content hashes are pinned by
[`CurrentChallengerRelease.ts`](../src/research/CurrentChallengerRelease.ts).
The runtime still requires explicit registry registration and a compatible
deployment; packaging does not write to a database or bypass adoption guards.

Training and historical diagnostic limits are documented in
[MODEL-C.md](../../docs/models/MODEL-C.md). Old model weights were removed
at the user's request; historical observations and prediction bundles remain.
No old-model archive is created by this package.
