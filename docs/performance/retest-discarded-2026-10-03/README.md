# Dati delle scelte scartate

Questa directory conserva le prove numeriche delle varianti fallite. L'unica
interpretazione documentale corrente, inclusa l'applicabilità a C, è nel
[catalogo delle scelte scartate](../../FORMULARIO-scelte-scartate.md). Non è una
roadmap né un'indicazione del modello adottato.

| File | Contenuto |
|---|---|
| `inventory.json` | Varianti, formule riproducibili e limiti |
| `metadata.json` | Impostazioni, input e protocollo dello studio |
| `final-table.json` | Risultati e criteri delle varianti |
| `paired-summary.csv` | Confronti appaiati complessivi |
| `paired-perLeague.csv` | Segmenti per campionato |
| `paired-perSeason.csv` | Segmenti per stagione |
| `paired-perLeagueSeason.csv` | Segmenti campionato/stagione |
| `verification.json` | Riscontri dell'esecuzione conservata |

Le date nei nomi identificano lo studio già consultato. Un NO-GO di A non prova
automaticamente lo stesso effetto su C; una formula ricostruita non è una replica
esatta se mancano coefficienti o cutoff originali. Non integrare varianti sulla
base dei soli miglioramenti puntuali e non trasformare questi dati in un nuovo
holdout indipendente. Il catalogo conserva risultati, interpretazione e limiti;
[Research](../../research-platform.md) definisce i vincoli degli eventuali studi
futuri. La conservazione degli asset non autorizza una nuova esecuzione.
