# FootPredictor 1.1.8 — nomi delle giocate

APK debug di prova, versione `1.1.8`, codice `10`, pacchetto
`it.footpredictor.personal`. Usa gli stessi motori sul backend condiviso.

Giocate, Archivio e dettaglio indicano la selezione esatta, per esempio
`1 — Torino vincente`, `1X — Torino o pareggio`,
`DNB 2 — Torino; pareggio rimborsato`, `Under 2.5 gol`.

La modifica riguarda la presentazione, senza cambiare consigli A/C, stake,
giocate archiviate o liquidazione. Il backend non viene modificato o ripubblicato.

pubblicati: **363/363 test frontend su 37 suite**, typecheck, lint,

di spazi ZIP non indicizzati del precedente pacchetto, non da runtime mancanti.
